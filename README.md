# Beauty Master Telegram Bot

Telegram-бот-візитка для б'юті-майстра на Python та aiogram 3.

## Що вміє бот

- показує коротку інформацію про майстра;
- показує послуги та ціни;
- показує портфоліо;
- приймає заявку на запис через FSM-форму;
- дозволяє клієнту обрати одну або кілька послуг кнопками;
- дозволяє клієнту обрати тільки доступну дату та час;
- тимчасово блокує вибране вікно після заявки;
- підтримує окремі графіки для різних адрес або майстрів;
- дає майстру адмін-панель для додавання та видалення вільних вікон;
- зберігає заявки в SQLite;
- надсилає заявку адміністратору;
- дозволяє адміністратору підтвердити або скасувати заявку;
- повідомляє клієнта про статус заявки.

## Головне меню

У боті залишено мінімум кнопок:

- `Записатися` — швидка заявка на запис;
- `Послуги` — список послуг і цін;
- `Портфоліо` — фото робіт;
- `Інфо` — коротко про майстра та контакти.

Під час запису клієнт обирає послуги кнопками. Можна вибрати одну або кілька послуг, потім натиснути `Готово`.

Після вибору послуг клієнт обирає адресу/майстра, дату і час. Бот показує лише ті години, які майстер заздалегідь додав як вільні.

## Адмін-панель

Адмін-панель відкривається командою:

```text
/admin
```

Доступ має тільки користувач з `ADMIN_ID` у `.env`.

В адмін-панелі можна:

- додати вільні вікна;
- вибрати окремий графік: студія, виїзд або інший майстер;
- ввести дату;
- ввести кілька годин одним повідомленням;
- переглянути найближчі вікна;
- редагувати час вільного вікна;
- видалити вільне вікно.

Приклад додавання часу:

```text
25.08
10:00, 12:30, 15:00
```

Якщо клієнт створює заявку, вибраний час переходить у статус `blocked`. Після підтвердження майстром він стає `booked`. Якщо майстер скасовує заявку, час знову стає доступним.

## Для чого потрібні файли

- `main.py` — точка запуску бота.
- `config.py` — читає `BOT_TOKEN`, `ADMIN_ID` і шлях до бази з `.env`.
- `database.py` — створює таблиці заявок, графіків і вільних вікон.
- `handlers.py` — основна логіка бота: меню, портфоліо, форма запису, вільні вікна, адмінські кнопки.
- `keyboards.py` — кнопки меню, вибору послуг, дат, часу, підтвердження заявки та адмінські кнопки.
- `states.py` — FSM-стани форми запису.
- `texts.py` — формування текстів для клієнта й адміністратора.
- `data.py` — дані візитки: опис майстра, послуги, контакти, портфоліо, графіки.
- `assets/portfolio/` — папка для фото робіт.

## Налаштування

1. Створіть бота через [@BotFather](https://t.me/BotFather).
2. Скопіюйте токен.
3. Дізнайтеся свій Telegram ID через [@userinfobot](https://t.me/userinfobot).
4. Скопіюйте `.env.example` у `.env`.
5. Заповніть `.env`:

```env
BOT_TOKEN=your_token_here
ADMIN_ID=123456789
DB_PATH=beauty_bot.db
```

## Запуск локально

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Як додати портфоліо

Додайте фото у папку:

```text
assets/portfolio/
```

Назвіть файли так:

```text
work_1.jpg
work_2.jpg
work_3.jpg
```

Якщо фото немає, бот покаже підказку, куди їх додати.

## Важливо

Бот не підтверджує запис автоматично і не вигадує вільний час. Клієнт залишає заявку, а майстер вручну підтверджує або скасовує її.
